# To-Do List (DCIT 26 Laboratory 2)

A responsive to-do list built with React, Vite, and Tailwind CSS.

**Author:** Vinoya
**Live site:** https://YOUR-PROJECT.vercel.app

## Features
- Add tasks (button or Enter key) with empty-input validation
- Mark tasks as Done or Not Done, with a status badge
- Delete a task, or clear the whole list
- Filter by All, Not Done, or Done
- User Guide section

## Run locally
```
npm install
npm run dev
```
